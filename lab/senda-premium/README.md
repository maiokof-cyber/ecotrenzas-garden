# EcoTrenzas Garden · Senda Premium Lab V1

Laboratorio aislado para validar una Senda visual premium sin modificar V0.2, V0.3 ni V0.3.1.

## Alcance Gate 1

- Vite como builder local.
- PixiJS como renderer 2D/2.5D.
- Vertical slice de cinco niveles.
- Estado lúdico únicamente en localStorage.
- Sin CRM, Booking, Make, API, pagos ni beneficios comerciales reales.
- Sin cambios en las versiones existentes de Garden.

## Desarrollo

1. npm install
2. npm run dev

## Build

npm run build

La salida queda en dist/.

## Rollback

Eliminar la rama lab/senda-premium-v1. La rama main y las versiones existentes permanecen intactas.
