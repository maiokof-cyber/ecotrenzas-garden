# EcoTrenzas Garden — G10 material finish

## Status
G10 lab production candidate. This branch derives from G9 GREEN; does NOT publish to main or replace G4.2 public. All commercial data and gameplay decisions are isolated.

## What changed
- Three G9 modular transparent image candidates are upgraded as G10 high-resolution painting-style material textures (wood/filigree, water strands and splashes, layered floral foliage).
- Existing G9 scene accepts an optional image path object. Default G9 paths remain unchanged.
- G10 scene reuses PixiJS, parallax, original approved node and gameplay, adding two lightweight cosmetic light sources.
- 1 E2E per viewport (390x844,1280x800). Asset size and SHA256 are recorded; no audio autoplay, reduced-motion respected, XP and coins never modified by scene.

## Art constraints
No asset was cut from the official Key Art; this is derivative of the G9 procedural source sprites. Art remains an **unapproved candidate**, not a statement of final polish. Avoid new paid tooling.

## Current deployment
Branch only, no `main` modification. Public G4.2 remains the stable link.
